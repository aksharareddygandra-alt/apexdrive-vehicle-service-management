## 🌟 Overview

**ApexDrive Service** is a Vehicle Service Management System developed as a Project-Based Learning (PBL) project.

The platform provides a centralized digital solution for managing vehicle maintenance and service operations. It allows customers to register their vehicles, schedule maintenance appointments, monitor repair progress, and access itemized invoices.

The system also provides an administrative interface to support service management and improve coordination between customers and workshop operations.

With a clean interface and organized service workflow, ApexDrive aims to make vehicle servicing more convenient, transparent, and efficient.

## ✨ Key Features

- **Vehicle Registration** – Register and manage vehicle information.
- **Online Service Booking** – Schedule vehicle maintenance and service appointments.
- **Multiple Service Categories** – Organize maintenance through eight specialized service categories.
- **Repair Progress Tracking** – Monitor service updates through a five-stage repair workflow.
- **Booking Status Tracking** – Check service progress using a unique Booking ID.
- **Customer & Admin Login** – Dedicated login interfaces for customers and administrators.
- **Transparent Billing** – Access itemized service invoices.
- **Interactive Dashboard** – Manage and monitor service-related information through a centralized interface.

## ⚙️ Getting Started

Follow these steps to run the project locally.

### Prerequisites

Make sure the following are installed:

- Node.js
- npm
- Git

### 1. Clone the Repository

```bash
git clone https://github.com/aksharareddygandra-alt/apexdrive-vehicle-service-management.git
```

### 2. Navigate to the Project Directory

```bash
cd apexdrive-vehicle-service-management
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Configure Environment Variables

Check the `.env.example` file and configure the required environment variables if needed.

### 5. Start the Development Server

```bash
npm run dev
```

### 6. Open the Application

Open the local URL displayed in your terminal (the configured Vite development server uses port 3000).

## 🔄 System Workflow

The application is designed around the following service workflow:

1. **Customer Registration** – Customers access the platform and provide their details.
2. **Vehicle Registration** – Customers register their vehicles.
3. **Service Selection** – Customers select the required maintenance category.
4. **Appointment Scheduling** – A service booking is created.
5. **Service Processing** – The workshop processes the vehicle through the repair stages.
6. **Progress Tracking** – Customers monitor their booking status.
7. **Invoice Generation** – Customers can access itemized billing information.
